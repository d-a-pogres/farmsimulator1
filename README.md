# farmsimulator1
В рамках лабораторной работы я разработала интерактивный симулятор роста растений. Мой проект состоит из следующих файлов и модулей:
―index.html – основная страница с панелью инструментов и игровым полем.
―styles.css – стилизация интерфейса.
―main.js – главный скрипт, управляющий логикой симуляции.
―grid.js – класс для работы с сеткой клеток.
―cell.js – классы клеток: базовая, земля и вода.
―plant.js – базовый класс растения.
―bogPlant.js, potato.js, cactus.js – конкретные культуры с уникальными параметрами.
―assets/ – папка с изображениями растений.
Логика работы программы:
Игровое поле – поле реализовано на canvas и разбито на клетки фиксированного размера. Каждая клетка может быть землёй или водой.
Влажность: для клеток земли рассчитывается влажность в диапазоне 0..1. Чем ближе клетка к воде, тем выше её влажность.
Растения: каждое растение имеет свои параметры: диапазон влажности, скорость роста и максимальную величину роста.
―Болотник любит высокую влажность и получает бонус при переувлажнении.
―Картошка предпочитает среднюю влажность и может некоторое время терпеть выход за пределы диапазона.
―Кактус растёт в сухих условиях, замедляется при повышенной влажности и погибает при сильном переувлажнении.
Пользователь может выбирать любой инструмент:
―Лопата – удаляет растение с клетки.
―Семена – высаживают выбранную культуру.
―Ведро с водой – превращает клетку в воду.
―Ведро для забора воды – превращает клетку обратно в землю.
Симуляция: каждую секунду выполняется шаг:
―пересчёт влажности;
―обновление состояния растений;
―перерисовка поля.
В результате работы получился симулятор, где можно экспериментировать с условиями для разных культур. Программа наглядно показывает, как растения реагируют на изменения окружающей среды.
